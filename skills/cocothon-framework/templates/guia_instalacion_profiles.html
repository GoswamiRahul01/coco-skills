Profiles de Cortex Code para AEs

Guía de instalación y uso — Demo Factory + Cocothon Organizer

Qué son los Profiles

Un Profile de Cortex Code (CoCo Desktop) es un archivo .md que configura al asistente para un flujo de trabajo específico. Cuando CoCo lee el profile, se convierte en un especialista que ejecuta todo automáticamente — solo necesitas decirle qué quieres.

Lo que tú haces vs lo que CoCo hace: Tú dices: "Quiero organizar una cocothon para Grupo Éxito, retail"
CoCo hace: Genera datos, configura cuentas, crea propuesta, materiales, y evalúa.

Profiles Disponibles

1. Demo Factory Crear demos SI

Archivo: CORTEX_CODE.md

Para qué: Clonar demos de Snowflake Intelligence para cualquier prospecto/industria en minutos. Genera datos ficticios, Cortex Search, Semantic Views, y Agentes listos para presentar.

Comando: "Clona OTIF_FINANZAS_TEMPLATE para [EMPRESA], sector [SECTOR]"

2. Cocothon Organizer Hackathons

Archivo: cocothon-organizer.md

Para qué: Organizar Cocothons (hackathons con Cortex Code) para clientes/prospectos. Te guía paso a paso: configuración, propuesta para el cliente, solicitud de cuentas HOL, datos, materiales, evaluación.

Comando: "Quiero organizar una cocothon para [EMPRESA]"

Instalación (5 minutos)

1Descargar Cortex Code Desktop

Si aún no lo tienes, descárgalo desde el portal interno de Snowflake o solicítalo a tu SE. Cortex Code Desktop es la aplicación de escritorio (CLI + interfaz) que ejecuta los profiles.

2Crear carpeta de trabajo

Crea una carpeta local donde CoCo almacenará los profiles y ejecutará su trabajo:

mkdir -p ~/Documents/snowflake-ae-tools
cd ~/Documents/snowflake-ae-tools

3Descargar los profiles

Descarga los archivos .md desde la carpeta compartida de Google Drive y colócalos en la carpeta que creaste:

ArchivoUbicación en DriveProfile
CORTEX_CODE.mdae-demo-handoff/Demo Factory
cocothon-organizer.mdcocothon-profile/Cocothon Organizer

Tu carpeta debe verse así:

~/Documents/snowflake-ae-tools/
├── CORTEX_CODE.md              ← Demo Factory (se lee automáticamente)
└── cocothon-organizer.md       ← Cocothon Organizer

4Abrir CoCo Desktop en la carpeta

Abre Cortex Code Desktop y navega a la carpeta ~/Documents/snowflake-ae-tools. CoCo lee automáticamente el archivo CORTEX_CODE.md como system prompt.

Nota importante: CoCo Desktop lee CORTEX_CODE.md automáticamente al abrir cualquier carpeta que lo contenga. Para activar el profile de Cocothon, simplemente di: "Usa el profile cocothon-organizer" o "Lee cocothon-organizer.md".

5Configurar conexión a Snowflake

Asegúrate de que CoCo Desktop esté conectado a tu cuenta Snowflake con tu role y warehouse asignados. Si no estás seguro, di a CoCo: "¿A qué cuenta estoy conectado?"

Uso: Demo Factory

Crear una demo de Snowflake Intelligence

Simplemente di:

"Clona OTIF_FINANZAS_TEMPLATE para Alpina, sector lácteos, ciudad Bogotá"

CoCo automáticamente:

  • Clona la DB template (estructura completa, zero-copy)
  • Genera 200-500 filas de datos ficticios del sector indicado
  • Crea 10-15 documentos de políticas para Cortex Search
  • Configura Cortex Search Service con indexación automática
  • Crea el Agente en Snowflake Intelligence con charting y tools
  • Ejecuta checklist de validación

Resultado: En ~3-5 minutos tienes un agente funcional en SI.

Uso: Cocothon Organizer

Organizar una Cocothon

Activa el profile y di:

"Lee cocothon-organizer.md"
"Quiero organizar una cocothon para Grupo Éxito, retail"

CoCo te guía paso a paso (interactivo):

  • Te pregunta empresa, industria, fecha, modalidad, formato
  • Sugiere problem statements relevantes para tu industria
  • Pregunta sobre cuentas (existente o solicitar HOL)
  • Genera la propuesta HTML para el cliente (lenguaje de negocio)
  • Genera solicitud de cuentas HOL con todos los features necesarios
  • Genera materiales de briefing y cheat sheet
  • Evalúa equipos post-evento y documenta resultados

Troubleshooting

ProblemaSolución
CoCo no lee el profileVerifica que estás en la carpeta correcta. Di: "Lee CORTEX_CODE.md"
"No tengo permisos"Verifica tu role con "SHOW GRANTS TO ROLE [tu_role]". Pide grants a tu SE.
Agente no aparece en SIDebe estar en SNOWFLAKE_INTELLIGENCE.AGENTS. Verificar con SE.
"agent spec is invalid"Modelo no disponible en la región. CoCo usa "auto" por defecto.
Cortex AI no funcionaVerificar cross-region inference habilitado. Pedir a SE.
Cocothon: no sé qué PS usarCoCo te sugiere opciones por industria. Solo elige.
